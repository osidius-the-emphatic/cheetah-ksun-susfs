# Стан проєкту

Створено початковий каркас Pixel 7 Pro (`cheetah`) на основі redfin-прикладу. Скрипти збірки та пакування перевірені на shell-синтаксис; збірка ядра, пакування образу й прошивка ще не запускалися.

Наступний крок: підготувати Linux/WSL checkout ядра та matching factory `boot.img`, виконати build, перевірити proof і лише потім пакувати образ.
